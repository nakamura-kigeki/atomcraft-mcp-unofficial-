# つまずき集(FAQ)

セットアップ・利用中によく起きることをまとめました。焦らなくて大丈夫です。当てはまるものを探してください。

## 一度動いたのに、次に頼んだら反応しなくなった

**これが一番よく起きるつまずきです。** さっきまで動いていたのに、「pingして」と頼んでも接続エラーになる場合です。

**原因**: Atom Craft側の「外部からの操作を受け付けるモード」(スクリプトサーバー)が止まっています。普段はつなぎ直しながら何度でも続けて使えますが、通信が異常な形で切れた後などに、たまにサーバー側が止まってしまうことがあります(発生条件は完全には特定されていません)。壊れたわけではありません。

**対処**: Atom Craft側でもう一度以下を実行してください。

```
スクリプトメニュー > サーバー > スクリプトサーバーを起動
```

これで直ります。**毎回この操作をする必要はありません**。つながらなくなったときだけで大丈夫です。

## Claude Codeで `/mcp` を見ると failed になっている・ツールが0個に見える

これは「本体そのものが起動できていない」状態です。原因は主に3つあり、上から順に確認してください。

1. **robot-path未設定**: `ATOMCRAFT_ROBOT_PATH` を設定しましたか? → [SETUP.md](SETUP.md) の手順3。設定後は必ずClaude Codeを再起動
2. **uvが未インストール、または入れた直後で認識されていない**: `winget install --id=astral-sh.uv -e` を実行しましたか? 入れた後にClaude Codeを開き直しましたか? → SETUP.md の手順2
3. **初回起動の待ち時間**: 一番はじめての起動は、uvが実行環境を組み立てるため数十秒かかります。failedに見えても、少し待ってから `/mcp` を見直すか、Claude Codeを開き直すと直っていることがあります

どれが原因か分からないときは、Claudeに「/mcp でatomcraftがfailedになっている。ログを見て原因を切り分けて」と頼むと、エラーメッセージ(どの手順が抜けているかの案内が入っています)を読んで特定してくれます。

## 「ポート9000に繋がらない」というエラーが出る

**原因**: Atom Craft側のスクリプトサーバーが起動していない状態です。ポート9000は、ClaudeとAtom Craftが会話するために既定で使う通信口の番号です。

**対処**: Atom Craftを起動し、操作したいプロジェクトを開いて、次のメニューを実行してください。

```
スクリプトメニュー > サーバー > スクリプトサーバーを起動
```

一度起動したのに繋がらない場合は、最初の「反応しなくなった」の項目と同じ状況です(もう一度実行すれば直ります)。もし社内ツール等がポート9000を既に使っている場合は、番号の変更方法が [docs/SETUP.md](../SETUP.md)(エンジニア向け)にあります。

## 「uvが見つからない」と出る

**原因**: uvがインストールされていないか、インストール直後でOSがまだコマンドの場所を認識していない状態です。

**対処**: PowerShellで `winget install --id=astral-sh.uv -e` を実行してください。すでに実行済みの場合は、ターミナルとClaude Codeを一度閉じて開き直してから、もう一度試してください(新しく入れたコマンドは開き直すまで見つかりません)。

## 時間のかかりそうな作業を頼んだら、途中で止まってしまう/失敗しやすい

**原因**: 数十件・100件を超えるような大きな作業を一度に頼むと、時間がかかるだけでなく、途中で1つ失敗したときに「どこまで終わっていて、どこからやり直すか」の把握が難しくなります。

**対処**: 大きな作業は、キャラクター単位・ユニット単位など小さいまとまりに分割して1つずつ頼んでください。「10キャラ分まとめて」ではなく「まずこのキャラだけキューシートを作って。確認したら次を頼みます」のように、**1つ終わるごとに内容を確認してから次へ進む**と、失敗しても被害がそのキャラ分だけで済みます。

## それでも解決しない場合

エラーメッセージをそのままClaudeに見せて「この案内の通りに対処して」と頼んでください(エラーには復旧手順の案内が組み込まれています)。より詳しい技術的な仕組みが知りたい場合は [docs/HANDBOOK.md](../HANDBOOK.md)(エンジニア向け)を参照してください。

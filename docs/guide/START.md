# これは何?

一言で言うと、Atom Craftの面倒な定型作業をClaudeに肩代わりしてもらう道具です。

**Atom Craft MCP** は、CRI Atom Craft(ボイス・SEのキューシートを作るサウンドオーサリングツール)の定型作業を、Claude(会話するAI)に頼めるようにします。MCP(Model Context Protocol)というのは、ClaudeのようなAIが外部のツール(この場合はAtom Craft)を操作できるようにする仕組みの名前です。難しいことは覚えなくて大丈夫です。「Claudeに指示を打つと、Atom Craftが実際に動く」くらいの理解で使い始められます。

## できることの例

導入が終わると、Claude Codeのチャットにこんな風に頼めるようになります。

- 「この台本シートと波形フォルダから、キューシートを一括で作って」
- 「このキューシートの登録内容を、台本と突き合わせて確認して」
- 「ビルドして」
- 「登録されているキューの数と台本の行数が合っているか確認して」

これまで手作業でAtom Craftのメニューをクリックしながら1件ずつ登録していた作業を、会話で頼んで代わりにやってもらえます。途中で何をしたかはClaudeが説明してくれるので、内容の確認もできます。

**なんでもできるわけではありません。** Atom Craftの全機能のうち、外部から操作できるように公開されている範囲(キューシート・マテリアル・カテゴリ・ミキサー・ビルドなどの主要な操作)が対象です。波形の切り貼りのような操作や、一部の細かい編集は今まで通りAtom Craftの画面で行います。何ができて何ができないかの正確な一覧は [CAPABILITIES.md](../CAPABILITIES.md) にあります(エンジニア向けの表ですが、「できること」の列は誰でも読めます)。

## 1つだけ大事な注意

Claudeに頼んだ操作は、**あなたが手で操作したのと同じように、開いているプロジェクトを実際に変更します**。だから一番大事な備えは、**プロジェクトをバージョン管理(SVNやgitなど、チームで使っている履歴管理の仕組み)に入れておき、Claudeに作業を頼む前の状態がコミット(チェックイン)済みであること**です。これさえできていれば、何が起きても頼む前の状態に戻せます。保存の扱いなど、その他の安全な頼み方は [USING.md](USING.md) にあります。

## 使う前に知っておいてほしいこと

- **このツールは実験的な段階です。** CRIツールのバージョンや環境によって不安定な動きをすることがあります。困ったら [FAQ.md](FAQ.md) を見るか、エラーメッセージをそのままClaudeに見せてください。だからこそ、次の節で述べるバージョン管理が大事です。
- **プロジェクトの情報をAIに渡すことになります。** キューシート名・キュー名・フォルダ構成・台本の内容などがClaude(クラウド上のAI)に送られます。タイトル未発表の名称や社外秘情報を扱う場合は、**所属組織のAI利用ポリシーに従ってください**(判断に迷ったら、組織の窓口に確認してから使うのが安全です)。

## 導入の全体像(4ステップ)

導入は大きく分けて4ステップです。詳しい手順は [SETUP.md](SETUP.md) にありますが、**手順書を自分で読み込む必要はありません** — おすすめは、Claudeにこう頼んで丸投げすることです:

```
docs/guide/SETUP.md の手順どおりに環境構築を進めて。各ステップで何をしたか報告して、私の操作が必要なところで止まって指示して
```

Claudeが手順を読んで進め、環境変数の設定やAtom Craft側のメニュー操作などあなたにしかできない箇所だけ案内してくれます。適宜確認しながら進めれば大丈夫です。

1. **プラグインを入れる** — Claude Codeに、Atom Craft MCPのプラグインを追加します(コマンド2行)
2. **uvを入れる** — この道具の本体を動かす実行環境を、自動で用意してくれるツールです(コマンド1行。Pythonを自分で入れる必要はありません)
3. **robot-pathを設定する** — 使っているAtom Craftと同じバージョンのCRIツールの場所をClaudeに教えます
4. **スクリプトサーバーを起動する** — Atom Craft側で「外部からの操作を受け付けるモード」をオンにします

この4つが終われば、Claudeに「pingして」と頼むだけで疎通確認ができます。

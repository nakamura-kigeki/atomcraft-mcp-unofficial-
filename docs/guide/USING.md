# 使い方実例集

セットアップが終わったら、あとはチャットで話しかけるだけです。「こういう風に頼めばいい」の例文と、安全な進め方、実際によく起きるトラブルの対処をまとめました。

## 大事なこと: 操作は本当にプロジェクトを変更します

Claudeに頼んだ操作は、あなたが画面の前で手を動かしたのと同じように、**開いているプロジェクトを実際に変更します**。安心して使うための原則を、効き目の大きい順に3つ挙げます。

1. **まずバージョン管理。これが一番の保険です。** プロジェクトをSVNやgitなど(チームで使っている履歴管理の仕組み)に入れ、**Claudeに作業を頼む前の状態がコミット(チェックイン)済みであることを確認してから**頼んでください。これができていれば、保存してしまった後でも頼む前の状態に戻せます。逆にバージョン管理がない状態では、以降の原則はどれも「保存するまで」しか守ってくれません。
2. **保存は独立した操作です。** 登録や作成をしても、保存は別の操作として頼まない限り実行されない設計です(心配なら「保存はまだしないで」と一言添えれば確実)。作ってもらった内容が意図と違ったら、保存せずにAtom Craft側でプロジェクトを閉じれば元に戻せます。「作って → 内容を確認して → OKだったら保存して」の順が基本です。
3. **削除や上書きは対象を具体的に。** 「いらないキューを消して」より「◯◯という名前のキューを消して」のほうが事故が起きません。また、Claude Codeは初期設定ではツールでの変更操作の前に許可を求める画面を出すので、そこでも内容を確認できます。

## 最初の一歩: まず構造を把握させる

新しいプロジェクトで作業を始めるときは、いきなり作業を頼む前に、まずこう頼んでください。

```
今のプロジェクトの構造をツリーで見せて
```

AIがプロジェクト全体(ワークユニット・キューシート・キューの階層)を把握した状態になると、その後の指示が正確に通るようになります。「◯◯のキューシート」のような曖昧な言い方でも正しい対象を見つけてもらいやすくなるので、セッションの最初の一手としておすすめです。

## こう話しかければいい

そのままコピペして、自分の状況に合わせて言葉を変えてもらって構いません。

- 「この台本シートと波形フォルダからキューシートを作って。**保存はまだしないで**」
- 「このキューシートの登録内容を台本と突き合わせて、抜けがないか確認して」
- 「確認できたので保存して」
- 「ビルドして」
- 「昨日作ったキューが鳴らない、登録内容を調べて」
- 「この波形フォルダ、重複しているファイルがないか調べて」
- 「今のプロジェクトの構造をツリーで見せて」
- 「このキャラのキューシート、台本の行数と登録されているキューの数が合っているか確認して」
- 「atomcraftにpingして」(接続確認したいとき)

一度に大きすぎる作業(数十キャラ分の一括登録など)を頼むと、時間がかかるうえに途中で失敗したときの巻き戻しも大変になります。**大きな作業はキャラ単位・ユニット単位で分けて頼み、1つ終わるごとに確認して次へ進む**のが安定します(詳しくは [FAQ.md](FAQ.md))。

## エラーが出たら

このツールのエラーメッセージには、「次にどうすればいいか」の案内(hint)が組み込まれています。エラーが出たら、メッセージをそのままClaudeに見せて「この案内の通りに対処して」と頼めば、多くの場合はそのまま復旧できます。自分でエラーの意味を解読する必要はありません。

## あるあるトラブルと対処

実際の制作作業でよく起きる「あれ?」を2つ。「失敗するとこう見える → こうする」の形でまとめています。

### 波形フォルダに「そっくりな重複ファイル」がある

**失敗するとこう見える**: 過不足チェックで、正規のファイルとほぼ同じ名前のファイルがもう1つ見つかる。

**原因**: ファイル名の先頭に目に見えない特殊文字(BOM)が混入した別ファイルが紛れていることがあります。ファイル一覧の見た目はそっくりでも、コンピュータ的には別のファイル名として扱われます。

**こうする**: 「そっくりな重複ファイルがある」と言われたら、単純な重複と決めつけず「ファイル名の先頭に見えない文字が入っていないか確認して」と頼んでください。

### 日本語のフォルダ名・ファイル名を扱う作業で、一部だけ失敗する

**失敗するとこう見える**: 日本語を含むフォルダやファイルを操作する作業で、「親フォルダの処理は成功したのに、中のファイルだけ失敗する」といった中途半端な失敗が起きる。

**原因**: 日本語(全角文字)を含むパスは、コマンドの通り道によって文字化けし、意図しない失敗を起こすことがあります。

**こうする**: 「一部だけ成功して一部だけ失敗する」という変な挙動が出たら、まず文字化けの問題を疑ってください。Claudeに「日本語パスが原因の可能性がないか確認して」と頼むと、文字化けしない別の経路に切り替えて再実行してくれます。

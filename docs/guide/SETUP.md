# やさしいセットアップ

Atom Craft MCPを使えるようにするための、実際の手順です。上から順番にやれば大丈夫です。
それぞれの手順の技術的な詳細(なぜこう作られているか等)は [docs/dev/SETUP.md](../dev/SETUP.md)(エンジニア向け)にまとめてあるので、興味があれば覗いてみてください。ここでは「何をすればいいか」に絞ります。

## 前提

- Windowsパソコンであること
- CRI Atom Craft本体がすでにインストールされていること(ライセンスをお持ちの方が対象です)
- Claude Codeが使える状態であること

Pythonを自分でインストールしておく必要はありません(次の手順2で入れる「uv」が自動で用意します)。

## 手順1: プラグインを入れる

Claude Codeのチャット欄に、次の2行を順番に打ち込んでください(コピペでOKです)。

```
/plugin marketplace add nakamura-kigeki/atomcraft-mcp
/plugin install atomcraft-mcp@atomcraft-mcp-marketplace
```

1行目でこのツールの配布元を登録し、2行目で実際にインストールします。

**Claudeに丸投げしている場合への注記(Claude向け)**: 上の `/plugin` はチャット専用の
書き方ですが、同じことはターミナルコマンドでも実行できます。丸投げされたClaudeは
ユーザーに打たせる代わりに、次の2コマンドを自分で実行してください
(リポジトリのcloneや手動でのMCP登録・スキルの手コピーは不要です。この
プラグイン方式が本ツールの正規の導入ルートです)。

```
claude plugin marketplace add nakamura-kigeki/atomcraft-mcp
claude plugin install atomcraft-mcp@atomcraft-mcp-marketplace
```

インストール後、以下のどちらかを行って設定を反映させてください。

```
/reload-plugins
```

または、Claude Code自体を一度終了して開き直してください。

## 手順2: uvを入れる

この道具の本体は、あなたのパソコンの中でPythonのプログラムとして動きます。ただし、Pythonを自分で用意する必要はありません。**uv** という「実行環境をまるごと自動で用意してくれるツール」を1つ入れるだけで、必要なPython(CRIのツールが対応しているバージョン3.10)も部品も、初回起動時に自動で揃います。

PowerShell(Windowsの標準ターミナル)で次のコマンドを実行してください。Claudeに「このコマンドを実行して」とチャットで頼んでもOKです。

```
winget install --id=astral-sh.uv -e
```

インストール後、**ターミナルとClaude Codeを一度閉じて開き直してください**(新しく入れたコマンドは開き直すまで見つからないため)。

**知っておくと安心**: 一番はじめての起動だけ、uvが実行環境を組み立てるため**数十秒ほど**かかります(このPCでの実測は初回約30秒)。2回目以降は数秒で起動します。初回に少し待たされても故障ではありません。

**すでにPythonを自分で管理していて、uvを使いたくない場合**は、[docs/dev/SETUP.md](../dev/SETUP.md)(エンジニア向け)に素のPython+pipでの代替手順があります。

## 手順3: robot-pathを設定する(Atom Craftの場所を教える)

Claude側に「操作の窓口になるCRIのプログラムがどこにあるか」を教えるステップです。設定名は `ATOMCRAFT_ROBOT_PATH` という環境変数(OSに登録しておく値)です。

**大事な原則が1つあります**: ここで指定するのは、**いま使っているAtom Craftと同じバージョン**のCRIツール配布物の中にある `robot\remote\Python` フォルダです。Atom Craftをバージョンアップしたら、この設定値も新しいバージョンのフォルダに更新してください。古いバージョンを指したままだと、新しい機能を頼んだときに「この機能は存在しません」という趣旨のエラーになります。

Windowsの画面から設定する手順は以下の通りです。

1. Windowsの検索バーで「環境変数」と入力し、「システム環境変数の編集」を開く
2. 表示されたウィンドウで「環境変数(N)...」ボタンをクリック
3. 上側の「(ユーザー名)のユーザー環境変数」欄で「新規(N)...」をクリック
4. 「変数名」に `ATOMCRAFT_ROBOT_PATH` と入力する
5. 「変数値」に、CRIツールをインストールしたフォルダの中の `robot\remote\Python` までのフルパスを入力する。例えば以下のような形です(実際のインストール場所とバージョンに合わせてください)。

   ```
   C:\path\to\cri_adx_tools_ver_X_XX_XX\cri\tools\ADX2\ver.3\robot\remote\Python
   ```

6. 「OK」を押してすべてのウィンドウを閉じる
7. **Claude Codeを一度完全に終了して開き直す**(環境変数は起動時にしか読み込まれないため、開いたままだと反映されません)

**失敗するとこう見える**: この設定を忘れたままだと、Claude Codeで `/mcp` を実行したときに `atomcraft` サーバーが「failed」と表示されたり、ツールが0個に見えたりします。「Atom Craftとの窓口がどこにあるか分からず、本体自体が起動できていない」状態です。→ 手順3をやり直し、Claude Codeを再起動してください。

## 手順4: スクリプトサーバーを起動する

Atom Craft本体を起動し、操作したいプロジェクトを開いた状態で、メニューから以下を実行してください。

```
スクリプトメニュー > サーバー > スクリプトサーバーを起動
```

これで、Atom Craftが「外部(Claude)からの操作を受け付けるモード」になります。

## 疎通確認(うまくいったか確かめる)

ここまで終わったら、Claude Codeのチャットで次のように話しかけてみてください。

```
atomcraftにpingして
```

「Connection alive(接続は生きています)」という趣旨の結果が返ってくれば、セットアップ完了です。ついでに「Atom Craftのバージョンを取得して」と頼むと、接続先のバージョン(例: Ver.3.57.02)が返ってきて、正しいAtom Craftにつながっていることまで確認できます。

次は [USING.md](USING.md) で実際の頼み方を見てみましょう。**うまくいかない場合**は [FAQ.md](FAQ.md) へ。

## あとで: 新しいバージョンに更新するとき

このツールは更新されることがあります。更新したくなったら、Claude Codeのチャット欄で
`/plugin` と打ってメニューから更新するのが簡単です。コマンドで済ませたい場合は、
ターミナルで次の2行を**この順番で**実行してください(Claudeに頼んでもOKです)。

```
claude plugin marketplace update atomcraft-mcp-marketplace
claude plugin update atomcraft-mcp@atomcraft-mcp-marketplace
```

**更新後はClaude Codeを一度閉じて開き直してください**(開いたままだと反映されません)。
入れ直し(アンインストール→再インストール)は不要です。

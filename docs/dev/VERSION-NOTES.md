# VERSION-NOTES.md — バージョン別概念差分ノート

CRI Atom Craft は Ver.3.41 系から Ver.3.57 系まで、実に120回以上のリリースを重ねている。
社内外のサウンド担当者がレガシーバージョン(3.4x系など)のプロジェクトで作業する際、
「本 MCP サーバーのドキュメントやツール説明に出てくる概念が、自分の手元の Atom Craft に
存在するかどうか」を素早く判断できるよう、Ver.3.41.00 以降の変更を要約したのがこの文書。

## この文書の読み方

- 節は **バージョン降順**(Ver.3.57 → Ver.3.41)に並んでいる。
- **自分が使っている Atom Craft のバージョンより上(新しい方)の節に書かれている概念は、
  自分の手元のツールには存在しない。** 例えば Ver.3.44.10 を使っている場合、
  「Ver.3.45系」以降の節に書かれている機能・仕様変更・用語はすべて自分のツールにはなく、
  「Ver.3.44系」以下の節の内容が自分のツールの状態そのものになる。
- 逆に、自分のバージョンより下(古い方)の節に書かれている内容は、通常は既に取り込まれて
  いる(過去の変更履歴)ため、読み飛ばしてよい。ただし「廃止・削除」の項目だけは例外で、
  自分のバージョンより新しいところで廃止された機能は、自分の手元にはまだ残っている
  （廃止版へアップデートすると消える）という意味になる。
- 各節は minor バージョン単位(例: Ver.3.46系 = Ver.3.46.00〜Ver.3.46.21 の総称)でまとめて
  いる。パッチバージョン単独では意味のある変更がないもの(不具合修正のみ)は個別の節にせず、
  該当 minor バージョンの節内に「(Ver.3.xx.xx)」のように差し込むか、省略した。
- Ver.3.42系・Ver.3.49系・Ver.3.53系は欠番(公式変更履歴上、当該バージョンのリリースが
  存在しない)。3.41→3.43、3.48→3.50、3.52→3.54と直接ジャンプする。

## 廃止・削除ダイジェスト(クイック参照)

自分のバージョンより新しい節で「廃止・削除」に載っている項目は、アップデートすると
消える機能。詳細は各節を参照。

| バージョン | 廃止・削除された概念 | 補足 |
|---|---|---|
| Ver.3.57.00 | インゲームプレビュー用バイナリ出力機能 | 通常バイナリでのインゲームプレビュー対応に統合 |
| Ver.3.57.00 | スクリプトプラグインの Python 3.7 / 3.8 / 3.9 | 3.10 / 3.11(Ver.3.55.00〜)のみに |
| Ver.3.57.00 | コマンドラインの `-ingame` オプション | 上記統合に伴い不要化 |
| Ver.3.57.00 | 色設定のリスト内色検索機能 | 色設定を任意色指定に変更したことに伴う |
| Ver.3.52.03 | ウェーブフォームリージョンの右クリックメニュー「参照先のオブジェクトをツリーに表示する」 | このメニュー自体 Ver.3.47.03 で追加されたばかりだった。選択時にマテリアルツリーを自動ハイライトする仕様に統合 |
| Ver.3.50.00 | プレビュースピーカー設定のヘッドフォンモード | Spatializer 対応に統合 |
| Ver.3.48.03 | (廃止ではなく非互換化)Ver.3.48.02 以前のツールでの当該プロジェクト保存 | プロジェクトのフォーマットバージョンが 1.04.02 に上がり、古いツールで開いたまま保存できなくなる |

## Ver.3.57系(2026-05-13〜2026-06-24: Ver.3.57.00 / .01 / .02)

**増えた概念・機能追加**
- 通常バイナリでのインゲームプレビューに対応(専用バイナリの出力が不要に)
- マルチバンドコンプレッサーにサイドチェイン入力バス設定を追加。Compressor / MultibandCompressor / Limiter に「サイドチェインミックス比率」「サイドチェインゲイン」パラメーターを追加(Ver.3.57.01でサイドチェインゲイン初期値を0dBに変更)
- キーボードショートカット機能、タグ機能を追加
- ツリーに検索機能・プロパティ値表示列を追加。検索でプロパティ値も検索可能に
- ツリー行に色を表示するオプションを追加。色設定は任意の色を指定できる方式に変更
- レベルメーターに総出力(TotalOut)表示を追加
- Perforce Plugin 向けに、波形更新時／キューシートビルド時の自動チェックアウトオプションを追加
- キュー・トラック・ウェーブフォームリージョンに「音源再生位置の振る舞い」を追加
- プロジェクト設定に使用する LipSync バージョンの設定項目を追加。LipSync Alive 解析データのバイナリ埋め込みに対応

**仕様変更**
- ビート同期情報の分子の上限値を128に変更(Ver.3.56.01でいったん32に修正されていたのが再拡大)
- 検索ウィンドウでフィルター可能なオブジェクトを追加。ツリーのソート操作をボタンからヘッダークリック方式に変更

**廃止・削除**
- インゲームプレビュー用バイナリ出力機能
- スクリプトプラグインの Python 3.7 / 3.8 / 3.9
- コマンドラインの `-ingame` オプション
- 色設定のリスト内色検索機能

**MCPツールへの影響**: なし(本リポジトリが依存する Robot API 関数の追加・削除の記載はこの範囲にない)

## Ver.3.55系(2025-04-01〜2025-09-11: Ver.3.55.00〜.10)

**増えた概念・機能追加(主に Ver.3.55.00)**
- 対応 Atom Library Ver.2.29.289以降
- ログペインを強化(設定項目・時刻非表示・ログタイプでのフィルター)
- ロボットのローカル実行が Python 3.10 / 3.11 系に対応(Ver.3.46.00でPython3.9対応だったのがさらに拡大)
- DSPエフェクト「IRリバーブ」を追加
- スタートページから Audio Stock のダウンロード WAV/AIFF をマテリアルへインポートする機能を追加
- Sound xR 向け HRTF ファイルの登録に対応(プロジェクト単位で HRTF を追加可能に)
- **ミキサー Version 2 に対応**。複数の出力バス作成、4〜7次までの Ambisonics、
  32/64/128chの Object-Based Audio に対応する大型機能。Ver.3.52.00で「DSPバス設定」から
  改称された従来の「ミキサー」とは別建ての新機能
- バスの非表示化機能、バスのソロ・ミュート機能、ラウドネスメーターを追加
- トラック・ウェーブフォームリージョンに任意のバスマップを設定する機能を追加
- (Ver.3.55.02)ロボットで、パラメーターパレットの「プレーヤーフェーダー」操作に対応
- (Ver.3.55.10)ロボットの `create_workunit` 関数が、ワークユニットサブフォルダーへの
  作成に対応

**仕様変更**
- パンニングの編集 UI を改修。ミキサー Version 2 使用時は出力ポートを操作できないように変更
- AISAC/オートメーション編集で、ポイントの X 軸位置に関わらず Y 軸編集が行えるように変更
- ターゲットコンフィグ「Switch」の表記を「Switch/Switch2」に変更(Ver.3.55.06)

**既知の罠(この範囲で修正された Robot API の不具合)**
- ロボットの `copy_object` 関数で **AISAC およびオートメーションのポイントがコピーできない
  不具合**。**Ver.3.47.00〜Ver.3.55.02 で発生**、Ver.3.55.03で修正。
- ロボットで関数の引数に日本語などのマルチバイト文字を使用すると正しく処理されない不具合。
  Ver.3.55.03で修正(それ以前のバージョンでは日本語引数が扱えない可能性)。

**MCPツールへの影響**
- `atomcraft_manage_workunit` でワークユニットサブフォルダーへの作成を行う場合、
  Ver.3.55.10以降が前提。
- `atomcraft_modify_object`(action=copy)でAISAC/オートメーションのポイントを含む
  オブジェクトをコピーする場合、Ver.3.47.00〜Ver.3.55.02の接続先では欠落する既知の不具合が
  ある(上記参照)。

## Ver.3.54系(2024-09-25〜2025-02-13: Ver.3.54.00〜.04)

**増えた概念・機能追加(主に Ver.3.54.00)**
- アクショントラックに「ターゲット識別条件」を追加(名前一致条件でターゲットを指定可能に)
- スナップショットの適用を可能にする「ミキサーアクショントラック」「スナップショット適用
  アクション」を追加
- AISAC・オートメーションのバスセンドグラフ1〜8で任意のバス名指定に対応
- 再生パラメーターアクションに「バスセンド」タイプと「センド先バス名」を追加
- 多くのオブジェクト(マルチタップディレイのタップ、キュー、トラック、ウェーブフォーム
  リージョン等)に「パン仰俯角」「パン仰俯角ランダム」項目を追加
- 32バンドEQのグラフ編集で複数バンドポイントの選択・移動、修飾キー+マウス操作に対応
- (Ver.3.54.03)スピーカー設定に「Windowsのスペーシャルオーディオ機能を有効にする」項目を追加

**仕様変更**
- 全体設定・ターゲットコンフィグの「デフォルトDSP設定」を「デフォルトミキサー」に名称変更
- タイムラインのウェーブフォームリージョン分割時、分割後のリージョンが分割元のパラメータを
  引き継ぐように変更
- ビルド時、エンコード後の波形ファイルの秒数が100ms以下だと警告を表示するように変更
- (Ver.3.54.04)ウェーブフォームリージョン複製操作の修飾キーを Alt から Shift+Alt に変更

**重要な既知の不具合(聴感に影響)**
- コンプレッサーの「アタック」「リリース」を編集した際、UI上の値より大きな値がプロジェクトに
  記録される不具合。**Ver.3.48.00〜Ver.3.53系で発生**、Ver.3.54.00で修正。
  この不具合の影響で、アプリでの実際の再生時にツールプレビュー時より緩やかな変化になる聴感上
  の差異が起きていた。この範囲のバージョンでコンプレッサーを使っている場合は設定値の確認・
  再調整が推奨されている(公式変更履歴内の注記)。
- ロボットの `copy_object` 関数で **AISACグラフ、オートメーショングラフがコピーできない
  不具合**。**Ver.3.47.00〜Ver.3.54.02で発生**、Ver.3.54.03で修正。

**MCPツールへの影響**
- `atomcraft_modify_object`(action=copy)でAISACグラフ／オートメーショングラフを扱う場合、
  Ver.3.54.03未満の接続先では欠落する既知の不具合がある。

## Ver.3.52系(2023-06-22〜2024-06-25: Ver.3.52.00〜.03。3.53系は欠番)

**増えた概念・機能追加(主に Ver.3.52.00)**

**仕様変更**
- **「ミキサー(DSPバス設定)」の表記を「ミキサー」に変更**。それ以前のマニュアル・変更履歴の
  「DSPバス設定」表記はこの機能を指している(呼称のみの変更、機能自体は同一)
- タイムラインのタイムベース設定「Bars/ビート」の拍数指定の最大値を 11 から 15 に変更
- **ロボットのスクリプトサーバーについて、ツール起動時に自動でサーバーを起動するように変更**

- (Ver.3.52.03)ブロックの「ブロックの終端ミリ秒」の表記を「ブロックの長さ」に変更

**廃止・削除**

  ツリーに表示する」を廃止。このメニュー自体はVer.3.47.03で追加されたばかりだった。
  選択時にマテリアルツリー側のマテリアルを自動ハイライトする挙動に統合された

**既知の罠**
- ロボットの `get_global_folder` 関数で、出力ポートフォルダー・ボイスプールフォルダー・
  ビート同期ラベルフォルダーが取得できない不具合。Ver.3.52.01で修正。

**MCPツールへの影響**
- **スクリプトサーバーの起動要否に注意**。Ver.3.52.00以降はツール起動と同時にスクリプト
  サーバーが立ち上がるが、Ver.3.52.00未満の Atom Craft に接続する場合は GUI から手動で
  スクリプトサーバーを起動する操作が必要な可能性が高い(本 MCP サーバーの利用手順にある
  「スクリプトメニュー > サーバー > スクリプトサーバーを起動」は、旧バージョンほど必須の
  前提操作になる)。
- ロボット経由でのウェーブフォームリージョンのトリミング／フェード操作は Ver.3.52.03以降。

## UNSUPPORTED_VERSION エラーとの関係

本リポジトリの新機能ツール(`atomcraft_preview` の新3アクション、`atomcraft_manage_beatsync`、
`atomcraft_bulk_property`)は、実際のAPI呼び出しの前に `versioning.require_feature` による
二段構えのゲートを通す。

1. **関数存在チェック(`hasattr`)** — 接続先のAtom Craft本体ではなく、`robot-path` が指す
   Robot Python側に対象関数が実際に存在するかを確認する。存在しなければ
   `UNSUPPORTED_VERSION` で確実にブロックする(`probe: "callable_missing"`)。これが実質的な
   防波堤になる。
2. **バージョン下限チェック** — `get_tool_version`(Ver.3.46.04で追加、上記参照)で取得した
   接続先バージョンが上表の `MIN_VER` 未満であれば `UNSUPPORTED_VERSION` で返す
   (`probe: "version_too_old"`)。バージョン取得に失敗した場合はブロックしない(fail-open)。

確度が「推定」の関数について `MIN_VER` を実際の初出バージョンより意図的に低く設定している
のは、バージョン比較だけでは確実に機能を止められない代わりに、関数存在チェックの方を
実質的な防波堤として機能させるための安全側の設計である。したがって、レガシーバージョンの
Atom Craft に接続してこれらのツールが `UNSUPPORTED_VERSION` を返した場合、エラーの
`details.probe` を見れば「バージョンが低いと判定されたのか」「そもそも関数が存在しない
(=`robot-path` が古い Python を指している可能性)のか」を区別できる。
